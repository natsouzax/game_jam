# JUNTOS (TOGETHER) — Windows Preview

Collect materials, build a tower, and climb together in this GameMaker platformer. Play solo or share a keyboard in local two-player co-op.

## Download and play

1. Download **JUNTOS-Windows.zip** from the assets below.
2. Extract the entire ZIP.
3. Open the extracted folder and double-click **Play.cmd**.

**Windows 64-bit / DirectX 11. No GameMaker installation required.**

The ZIP includes `TOGETHER.exe` and its required data and opening video. Keep all files together. The GitHub “Source code” archives are for development; choose **JUNTOS-Windows.zip** to play.

See the [README](https://github.com/natsouzax/game_jam#readme) for controls, screenshots and credits.

This release packages the existing Windows preview without rebuilding it. Physical controller support and compatibility on other PCs remain unverified.
